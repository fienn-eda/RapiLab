# 스노우 화이트 — 무기변환 중 소장품 적용 실측

Fienn이 2026-08-03에 사격장에서 판독한 원본 수치와, 그로부터 나온 파생값. **원본
수치는 절대 편집하지 않는다** — 모델이 바뀌면 해석만 바꾼다.

이 기록이 존재하는 이유: `damage-formula-reference.md:77`의 *possible unintended
error* 항목 — "무기변환 중인 니케는 장착한 소장품의 고유 스탯 보정을 못 받는다
(Zwei, Nayuta, K, Snow White, E.H.에게 악영향)" — 을 검증하기 위함이다. 스노우
화이트가 그 명단에 이름으로 올라 있었다.

## 측정 조건

- 덱: 아니스 / 브리드 / 솔린 / 헬름: 아쿠아마린 / 스노우 화이트
- 작열 속성 사격장(수냉 약점), NEAR 위치
- 스노우 화이트의 소장품: SR 등급, 레벨 15 → 코어 대미지 17.04%
- 판독 두 개, 둘 다 논-크리티컬: 평타(normal AR), 그리고 그녀의 버스트 무기변형
  (Seven Dwarves: I)이 쏘는 변형샷

## 원본

```
평타 (normal AR):              논코어 61254      코어 132946
버스트 변형샷 (무기변환 중):    논코어 56341999   코어 100303780
```

## 파생값

메이저 배율 버킷을 가산 `1 + 코어 + 풀버스트 + 사거리`로 읽는다(스노우 화이트는
AR이라 NEAR 위치에서 사거리 항이 0).

```
평타 (풀버스트 밖, 분모 1.0):
  실측 비 = 132946 / 61254 = 2.1704052
  예측    = (1 + 1.0 + 0.1704) / 1 = 2.1704000
  잔차 5.2e-06

변형샷 (풀버스트 안, 분모 1.5):
  실측 비 = 100303780 / 56341999 = 1.7802666
  예측    = (1.5 + 1.0 + 0.1704) / 1.5 = 1.7802667
  잔차 4.9e-08
```

"소장품이 무기변환 중엔 적용되지 않는다"는 대안 가설은 변형샷에서
`2.5 / 1.5 = 1.6666667`을 예측한다 — 실측과 6.8% 어긋나 배제된다.

분모 1.5(풀버스트 중 논코어 버킷)는 이 측정으로 새로 피팅한 값이 아니다.
`docs/insights.md:302`가 이미 다른 유닛(볼륨) 실측에서 「버킷 1.500000. 풀버스트만,
코어 없음, 사거리 없음」을 확정해 두었다. 이 예측은 자유 모수가 0개다.

## 판정 — 소장품은 무기변환 중에도 적용된다

`damage-formula-reference.md:77`의 *possible unintended error*는 최소한 스노우
화이트에 대해서는 반증됐다. 무기변환된 버스트 샷도 소장품의 코어 대미지 보정을
정확히 받는다. 이 반증이 곧 `arcana_fortune_mate.py`/`nayuta.py` 쪽 버킷 이관
결정의 방향이 옳았다는 독립 확인이다 — `docs/decisions.md` 참고.

## 이 측정이 가르지 못한 것

- **RL·SR 소장품의 "weapon" 배치.** 스노우 화이트의 소장품은 AR 코어 대미지로
  `"effect"` 배치(영구 self Effect, 레지스트리의 가산 버킷을 거쳐 세그먼트 안팎
  어디서든 균일하게 읽힌다)다. RL·SR의 차지 대미지 소장품(`charge_damage_percent`,
  `"weapon"` 배치 — 세그먼트가 직접 참조하는 정적 무기 스탯 dict를 읽는 경로)은 이
  측정이 전혀 건드리지 않았다. 그쪽은 `docs/engine-gaps.md`에 남아 있는 별개의,
  실측으로 확인된 갭이다.
- **Zwei, K, E.H.** 이 측정은 스노우 화이트 한 유닛만 봤다. 나머지 명단은 직접
  검증하지 않았다(다만 Zwei·나유타는 이번 브랜치의 SG·SMG 버킷 이관 결정으로
  구조적으로 같은 결론에 도달했다 — `docs/decisions.md` 참고).
- **다른 무기군·다른 소장품 등급으로의 일반화.** SR 레벨 15 AR 코어대미지 소장품
  하나로 확인됐을 뿐, R 등급이나 다른 무기군에서 같은 배치가 같은 결과를 내는지는
  미검증이다.
