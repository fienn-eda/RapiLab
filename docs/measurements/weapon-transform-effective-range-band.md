# 무기변형과 유효사거리 밴드 — 나유타 실측 기록

Fienn이 2026-08-03에 사격장에서 판독한 원본과 파생값.
**원본 수치는 절대 편집하지 않는다** — 모델이 바뀌면 해석만 바꾼다.

이 기록이 존재하는 이유: `raid_simulator._in_effective_range`가 세그먼트 샷에도
**유닛의 기본 무기** 밴드를 쓰는데(`weapon_stats[slug]["weapon"]`), 무기군을 바꾸는
변형이 둘 있어 그 가정이 검정된 적이 없었다. 사거리 항은 major 버킷의 `+0.3`이라
틀리면 그 창의 데미지가 17~23% 어긋난다.

## 왜 나유타가 판정할 수 있는가

무기변형이 무기군을 실제로 바꾸는 유닛은 둘뿐이다.

| 유닛 | 기본 무기(밴드) | 변형 프로파일(밴드) |
|---|---|---|
| **nayuta** | SMG (`near`) | `"SR"` (`far`) |
| moran | AR (`mid`) | `"SMG"` (`near`) |

NEAR에서 나유타의 기본 SMG는 밴드 안이고 `"SR"` 프로파일은 밴드 밖이다. 두 가설이
major 버킷을 0.3만큼 벌리므로 코어/논코어 비율에서 바로 갈린다. 맥스웰 판독은 이걸
가르지 못했다 — 그의 기본과 프로파일이 둘 다 SR이라 차이가 나지 않는다.

## 측정 조건

- 편성 **로자나 / 나유타 / 아인** — 로자나·아인은 아군 대상 구절이 0개다
- 사격장 **NEAR** 위치, 논크리 판독
- 나유타 스킬 10/10/10
- 코어/논코어 비율은 ATK·버프·무기계수를 전부 상쇄하므로, 제약은 **코어 대미지
  소스** 하나뿐이다. 그녀 자신의 Hypocrisy가 그것을 하나 갖고 있고(아래), 그 값은
  판독에서 직접 역산된다

## 원본 — 코어 ÷ 논코어

```
FB OFF (기본 SMG 평타)        161627 / 82349        기억흡수 11중첩
FB ON  (Memory Incineration)  18505755 / 10916061   기억흡수 15중첩
```

## 파생값

major 버킷은 `1 + 코어(1.0) + 코어소스 + 풀버스트×0.5 + 사거리×0.3`
(`damage_formula.py`). 논크리 단발이므로 코어 ÷ 논코어 `= (M + 1 + X) / M`이고,
여기서 `M`은 코어 항을 뺀 버킷, `X`는 코어 대미지 소스다.

**코어 소스 X는 두 판독이 각각 독립으로 되돌려준다.**

```
FB OFF에서   X = 1.9627075 × 1.3 − 2.3 = 0.251520
FB ON에서    X = 1.6952777 × 1.8 − 2.8 = 0.251500
```

나유타 Hypocrisy의 「Memory Absorption 발동 시 전 아군 **코어 대미지 ▲25.15%**
5초」다(3초마다 발동하므로 상시). 두 판독의 **기억흡수 중첩 수가 11과 15로 다른데
같은 값이 나온다** — 이 버프가 스택 비례가 아니라 고정값임을 함께 확정한다.

### 판정

```
FB OFF   M = 1 + 0.3        예측 1.9626923   실측 1.9627075   잔차 1.5e-05
         (사거리 없었다면 M = 1.0 → 2.2515000, 실측과 14.7% 어긋남)

FB ON    기본무기 밴드 유지  M = 1 + 0.5 + 0.3 = 1.8   예측 1.6952778   실측 1.6952777   잔차 5.8e-08
         프로파일 밴드(SR)   M = 1 + 0.5       = 1.5   예측 1.8343333                  8.20% 어긋남
```

**변형 중에도 기본 무기의 유효사거리 밴드를 유지한다.** `_in_effective_range`가
`weapon_stats`에서 무기를 읽는 현재 구현이 옳다.

### 함께 확정된 것

- **SMG는 NEAR에서 사거리 항 +0.3을 받는다.** 사거리 항이 없다면 FB OFF가
  2.2515여야 하는데 실측은 1.9627이다
- **풀버스트 항 +0.5.** 두 M(1.3 → 1.8)의 차이가 정확히 0.5다
- **Hypocrisy의 코어 +25.15%는 스택 무관 고정값** (위 참고)

## 이 측정이 가르지 못한 것

- **moran의 방향.** 그녀는 AR(`mid`) → SMG(`near`)로, 나유타와 반대 방향이다.
  기본 무기 밴드를 유지한다는 결론이 무기군에 무관한 규칙이라면 그녀에게도
  적용되지만, 그 자체를 잰 것은 아니다
- **밴드가 프로파일을 아예 안 보는지.** 확인된 것은 「기본 무기 밴드가 유지된다」
  까지다. 프로파일 무기가 기본과 **같은 밴드**일 때는 두 가설이 구별되지 않으므로,
  프로파일이 밴드를 넓히는 경우(예: 기본이 밴드 밖인데 프로파일이 안)는 미검정이다
