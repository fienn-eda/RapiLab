# 소장품 차지대미지 배율 × 무기변형 — 맥스웰 실측 기록

Fienn이 2026-08-03에 사격장에서 판독한 원본과 그로부터 나온 파생값.
**원본 수치는 절대 편집하지 않는다** — 모델이 바뀌면 해석만 바꾼다.

이 기록이 존재하는 이유: RL·SR 소장품의 「차지 대미지 배율」이 무기변형 세그먼트의
차지 대미지에도 붙는지를 확정하고, 그 위에서 `maxwell`·`red-hood`의 인코딩이
배율을 소비하게 만들었다(`docs/engine-gaps.md`).

## 왜 맥스웰이 판정할 수 있는가

그녀의 Pierce Shot 변형은 **버스트당 1발**이고, 그 뒤 같은 풀버스트 창 안에서 기본
SR 평타가 재개된다. 두 사격 유형이 같은 버프 상태 안에 놓이므로 비율로 비교할 수
있다. 변형 무기의 풀차지 배수가 **통째로 스킬 값**(가산 항 없음)이라는 것도 중요하다
— 레드후드·스노우화이트: 헤비암즈는 두 항의 합이라 어느 항에 배율이 붙는지를 못
가른다.

## 측정 조건

- 편성 **로자나 / 센티 / 맥스웰** — 셋 다 차지대미지 버프도 코어대미지 버프도 주지
  않는다. 맥스웰 자신의 Straight Shot이 거는 ATK +43.1%는 풀버스트 진입 시 10초라
  두 판독 모두에 켜져 있어 약분된다. Spark Shot은 적 5기 이상 조건이라 걸리지 않는다
- **작열 속성 사격장**(수냉 약점), **MID** 위치
- 맥스웰 스킬레벨 **1/1/1** — Pierce Shot lv1은 차지 2초, 데미지 144.85%,
  풀차지 300%
- 맥스웰 소장품 **SR 5단계** — 차지 대미지 6.31% → 배율 1.0631
- 기본 무기 SR: 데미지 69.04%, 풀차지 250%
- 전부 **논크리** 판독

## 원본

```
사이클 A   변형샷 코어   7014461    기본풀차지 코어 2786144   기본풀차지 논코어 1671686
사이클 B   변형샷 논코어  4208677    기본풀차지 코어 2786144   기본풀차지 논코어 1671686
```

두 사이클의 기본무기 값이 **완전히 동일**하다 — 덱 상태가 같았다는 대조군이다.

## 파생값

### major 버킷을 판독에서 직접 뽑는다

맥스웰의 소장품은 차지 대미지라 코어 소스가 0이므로 `코어/논코어 = (M+1)/M`이고,
`M = 1/(비율−1)`이다.

| 사격 | 코어/논코어 | M |
|---|---|---|
| 기본 무기 | 1.6666671 | **1.4999991** |
| 변형샷 | 1.6666665 | **1.5000004** |

둘 다 **1.5** — 풀버스트만, 코어 소스 없음, 사거리 항 없음. M이 같으므로 논코어
비교에 보정이 필요 없다.

### 판정

```
논코어 비율 (변형샷 ÷ 기본풀차지)                        2.5176220

  배율이 세그먼트에도 붙는다   (144.85×3.00) ÷ (69.04×2.50)   2.5176700   잔차 +4.9e-05
  안 붙는다                    위 ÷ 1.0631                    2.3682400   잔차 -1.5e-01
```

**붙는다.** 자유 파라미터가 없는 예측이 5e-05 안에서 맞고, 반대 가설은 6.3%
어긋난다.

## 이 판독의 캐비엇 — 비율은 공통 인자에 눈이 멀다

위가 **엄밀히** 말하는 것은 `k_변형 = k_기본`이지 `k = 1.0631`이 아니다. 분자와
분모에 같은 인자가 있으면 비율은 그것을 보지 못한다.

기본 무기 쪽이 1.0631이라는 것은 **에이드: 에이전트 바니의 사격장 판독 7개**가
확정했다 — 비율이 아니라 절대값 적합이고, `250% × 1.0631 = 265.775%`로 7개 전부
0.002% 안에서 맞았다(`docs/engine-gaps.md`). 이 측정은 그 위에 얹혀야 체인이 닫힌다.
에이드 결과가 뒤집히면 이 결론도 함께 재검토해야 한다.

## 함께 드러난 것 — 변형 캐논은 `mid` 밴드가 아니다

MID 위치에서 **두 사격 모두 M = 1.5**, 즉 사거리 항이 0이다. SR의 유효사거리 밴드는
`far`이므로 기본 무기가 0인 것은 예상대로이고, 변형 캐논도 0이라는 것은 그것이
`mid` 밴드(AR·MG)로 취급되지 않는다는 뜻이다. `far`인지 `near`인지는 이 측정이
가르지 못한다.

## 2차 판독 — 차지댐 「버프」에는 붙지 않는다 (헤비암즈, 2026-08-03)

맥스웰 판독은 **변형 무기의 기본 차지댐**에 배율이 붙는 것까지만 보였다. 남은
질문은 「Charge Damage ▲ N%」로 들어오는 **버프**에도 붙는가였고, 이것은 변형
유닛만의 문제가 아니라 소장품 낀 RL·SR이 아무 차지댐 버프나 받을 때마다 걸린다.
`references/damage-formula-reference.md`가 「other charge-damage sources not
considered」라고 적어두었지만, 에이드 판독 7개에는 차지댐 소스가 하나도 없어
그 절은 검정된 적이 없었다.

### 왜 헤비암즈가 판정할 수 있는가

로스터의 차지댐 버프 여섯 개가 전부 **ATK 버프와 같은 트리거에 묶여 있어**, 버프
전/후 단순 비교는 ATK 변화를 같이 물고 온다. 헤비암즈는 한 번의 풀차지에서 두
숫자를 동시에 뱉는다 — 차지샷 본체(차지 배수를 먹음)와 Auto Fire의 41.9% 전체히트
(안 먹음). 둘이 **완전히 동시**이므로 비율의 비율이 ATK·Attack Damage를 지운다.

### 측정 조건

- 편성 **라피 / 크라운 / 헤비암즈 / 프리바티**, 헤비암즈 외 전원 엄폐로 평타 봉쇄
  (크라운 20스택 고정, 프리바티 마지막 탄 효과 방지)
- **철갑 속성 보스**(풍압 약점)
- 헤비암즈 스킬 10/10/10, 소장품 SR 15단계 → 1.0947, 기본 차지댐 250%,
  Shades of White 「Charge Damage ▲ 528% for 1 round」
- 전부 논크리, 차지샷은 논코어

### 원본

```
Fully Active ON    차지샷 30371215    41.9% 히트 2299187
Fully Active OFF   차지샷  6849107    41.9% 히트 1518812
```

### 파생값과 판정

```
차지샷    ON/OFF = 4.4343321
41.9히트  ON/OFF = 1.5138062      <- ATK·Attack Damage 몫, 여기서 약분된다
R = 비율의 비율    = 2.9292601

  버프는 배율을 안 먹는다   (2.50×1.0947 + 5.28) / (2.50×1.0947)  2.9292957   잔차 3.6e-05
  버프도 스케일된다         (2.50 + 5.28)×1.0947 / (2.50×1.0947)   3.1120000   6.24% 어긋남
```

**버프에는 붙지 않는다.** 레퍼런스의 괄호절이 이로써 실측으로 확인됐다.

### 이 판독은 기본 차지댐 쪽도 함께 확정한다

소장품이 **기본 차지댐에도 안 붙는다면**(k=1, 버프도 안 붙음) R은
`(2.50+5.28)/2.50 = 3.112`로 「버프도 스케일」과 **같은 값**이 된다. 실측 2.9293은
그 경우도 배제하므로, 이 한 판독이 **기본 차지댐은 ×1.0947이 붙고 버프에는 안
붙는다**를 동시에 낸다 — 에이드 판독의 결론이 다른 유닛·다른 편성에서 독립으로
재확인된 셈이다.

## 이 측정이 가르지 못한 것

- **변형 캐논의 유효사거리 밴드.** MID에서 0이라는 것만 확인됐다. 맥스웰은 기본과
  프로파일이 둘 다 SR이라 애초에 가를 수 없었다 — 무기군을 바꾸는 나유타로 따로
  쟀고, 변형 중에도 **기본 무기 밴드를 유지한다**가 확정됐다
  (`docs/measurements/weapon-transform-effective-range-band.md`)
- **스킬레벨 의존성.** lv1에서만 읽었다. 슬롯값이 레벨을 타는 것은 데이터가
  말해주지만, 배율이 붙는 위치가 레벨을 탈 이유는 없다

## 재지 않고 닫은 것과 그 근거

아래 셋은 실험을 설계할 수 있지만 **커밋된 게임 데이터 테이블이 확인한 칸마다
맞았다**는 이유로 닫는다. 나중에 반례가 나오면 이 문단이 되돌릴 지점이다.

- **RL과 SR이 다른가.** 둘은 **같은 group_id를 쓴다** — R 등급 711301, SR 등급
  712301이 두 무기군 공통이고, 사다리 값도 글자 그대로 같다
  (`4.74 / 6.31 / 7.89 / 9.47`). 무기군별로 갈릴 구조 자체가 테이블에 없다.
- **SMG와 SG가 다른가.** group_id는 다르지만(712501 / 712901) 사다리가 동일하고
  (`4.73 / 6.3 / 7.88 / 9.46`) 매핑도 같은 스탯
  (`normal_attack_damage_multiplier`)이다. 더구나 SMG에는 버킷을 찔러볼 두 번째
  NADM 소스를 가진 유닛이 로스터에 없어 판별 수단 자체가 없다.
- **사다리의 남은 두 칸.** 네 칸 중 둘이 이미 **각각 두 유닛에서** 검증됐다 —
  rung 2(6.31)는 에이드와 맥스웰, rung 4(9.46/9.47)는 포츈메이트(SG)와
  헤비암즈(SR). 넷 다 테이블 값과 정확히 맞았다. rung 3(소장품 레벨 10~14)은
  해당 레벨의 유닛이 로스터에 하나도 없어 측정 대상이 없고, rung 1은 같은
  테이블을 다른 인덱스로 읽는 것뿐이다.
