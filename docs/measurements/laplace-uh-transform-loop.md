# 라플라스: 얼티메이트 히어로 — 변형 루프 실측 (2026-08-17)

무기 변경(Electric Power, Fully Full Charge) 한 바퀴를 프레임으로 잰 것. 60fps.

**이 판독이 정한 것:** 변형 무기의 연사가 **초당 24발**이고, 무기 변경에 **모션
지연**이 있으며, 그래서 한 바퀴가 얼마인지.

**앞선 판독(`charge-speed-scaling.md`)의 「주기 16.1초」를 대체한다.** 그 값이 큰
이유는 미모델 항이 아니라 **사격장 보스가 잠깐씩 사라지는 순간**이었다 — 그 타이밍에
조준이 풀리고 연사가 끊긴다. 여기서는 **연사가 유지되는 구간만** 골라 쟀다.

## 조건

- 사격장. **부계정**이라 스킬레벨 전부 1(그래서 Warm Up 램프가 Lv10보다 느리다 —
  `charge-speed-scaling.md`의 「스택당 5%」 항목이 같은 사실의 다른 얼굴이다).
- **재장전 큐브 Lv15 착용** = 렐릭 베어(Resilience) 재장전속도 **29.69%**.
- 변형 무기의 표기 탄창은 120발(`Max Ammunition Capacity: 120`, 레벨 무관).

### 연사 — 초당 24발 (Fienn 판정)

한 탄창이 293 / 292프레임에 걸친다. 발 사이 간격은 **약 2.5프레임**이고, 이것이
무기군 SMG 상수(20발/초 = 3프레임 간격)를 **직접 반증한다** — 3프레임이면 같은
탄창이 357프레임이어야 한다.

탄창을 몇 발로 놓느냐에 따라:

| 탄창 | 293f | 292f |
|---:|---:|---:|
| 118발 | 23.96발/초 | 24.04발/초 |
| 120발 | 24.37발/초 | 24.45발/초 |

**Fienn이 24발/초로 정했다.** 표기 120발로 정확히 24발/초면 창이 297.5프레임이라
판독보다 4.5프레임 길다 — 그만큼은 미해결이고, 이 판독만으로는 「그 계정 탄창이
정확히 몇 발인가」를 못 가른다(첫탄·마지막탄만 있고 중간 발은 없다).

### 무기 변경 모션 — 37프레임

재장전 완료(1737)에서 다음 첫탄(2042)까지 **305프레임**. 그 사이에 들어가는 것은
Warm Up 빌드(풀차지 5발) + 무기 변경 모션이다. 같은 계정·같은 레벨의 빌드 구간은
`charge-speed-scaling.md`의 판독에서 **268프레임**(60·56·52·51·49)이므로,

```
305 − 268 = 37프레임 = 0.617초
```

**★ 이 37프레임은 두 가지를 합친 값이다** — 「재장전 완료 → 차지 시작」의 입력 지연과
「5번째 풀차지 → 첫 변형탄」의 무기 변경 모션. 이 판독은 둘을 가르지 못한다. 엔진은
전부 모션으로 잡는데, 한 바퀴 전체가 그래야 맞기 때문이다(아래). 빌드 값이 **다른
녹화**에서 온 것도 캐비엇이다.

### 재장전 — 아핀 모델의 공짜 검증

판독 **115프레임 = 1.917초**. 엔진 모델은
`reload_time × (1 − s) + RELOAD_FIXED_SECONDS`이고,
파일값 2.5초 · 렐릭 베어 Lv15의 29.69%를 넣으면

```
2.5 × (1 − 0.2969) + 0.148 = 1.906초 = 114.3프레임     (판독 115프레임)
```

**0.7프레임 차이.** 다른 목적으로 잰 판독이 아핀 재장전 모델과 고정 구간 0.148초를
독립적으로 확인해 준다.

## 엔진에 반영한 것

```
주기 = Warm Up 빌드 + 무기변경 모션 + 창 + 재장전
     = 4.0 + 0.617 + (탄창 ÷ 24) + reload_time_with_speed(2.5, 0)
     = 4.0 + 0.617 + 5.0 + 2.648 = 12.265초   (표기 120발 기준)
```

- 연사 상수는 `TRANSFORM_RATE_OF_FIRE = 24.0`. **무기군 SMG 상수(20.0)로 되돌리지
  말 것** — 그 값은 공칭 1440rpm(24.00/초)을 3프레임 격자로 **올림**한 것이고, 이
  무기는 그 격자 위에 있지 않다는 것이 이 판독이다.
- 재장전 항을 무음 세그먼트와 **같은 식**으로 맞췄다. 예전엔 주기가 파일값 2.5초를,
  무음 세그먼트가 2.648초를 써서 0.148초 어긋나 있었다.
- 딜 영향: 그녀 본인 **+8.56%**, 덱 **+3.22%**(코어 48.89px · DEF 8000 · 180초).

## 이 판독과 엔진 값의 관계 (숫자가 왜 다른가)

엔진 12.265초 대 판독 11.883초는 **계정 차이가 전부**다:

| | 엔진(Lv10·큐브 무버프) | 이 판독(Lv1·큐브 Lv15) |
|---|---:|---:|
| 빌드 | 4.000 | 4.467 |
| 모션 | 0.617 | 0.617 |
| 창 | 5.000 | 4.883 |
| 재장전 | 2.648 | 1.917 |
| 합 | **12.265** | **11.883** |

## 이 판독이 정하지 못한 것

- **그 계정의 실제 탄창 수.** 118이면 24발/초가 정확히 맞고 120이면 24.4발/초다.
  가르려면 중간 발이 있는 판독이나 인게임 표기 탄창 수가 필요하다.
- **37프레임의 내역.** 입력 지연과 무기 변경 모션의 비율. Fienn은 모션을 「몇 프레임
  정도」로 보고 있어, 나머지가 지연이라면 모션 상수는 더 작고 빌드 앞이 더 길다 —
  한 바퀴 총합은 어느 쪽이든 같으므로 딜은 안 바뀐다.
- **본계정에서의 한 바퀴.** Lv10 빌드 4.0초와 무버프 재장전으로 12.265초가 나오는지는
  아직 직접 재지 않았다.
