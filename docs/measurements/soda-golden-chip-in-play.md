# 소다: 트윙클링 바니 — 실전 운영에서의 골든칩 궤적

Fienn이 2026-08-06에 실제 전투에서 읽은 수치와, 그것이 무엇을 결론지었는지.
**원본 수치는 절대 편집하지 않는다** — 모델이 바뀌면 해석만 바꾼다.

이 기록이 존재하는 이유: 같은 날 골든칩 소비를 「17로 세팅」에서 「17 감산」으로
고친 직후(`docs/decisions.md`), 시뮬레이터는 그녀의 칩이 전투 내내 **고갈된다**고
답했고 나는 그 궤적을 근거로 Beginner's Rewards의 풀 버스트 확장을 「순환이라
상수로 접을 수 없다」며 보류로 남겼다. Fienn의 실측은 그 결론을 뒤집는다 —
**실전에서 칩은 고갈되지 않고 33~50 사이에서 순환한다.** 그 차이를 만드는 것이
바로 보류해 둔 그 확장이라, 판단의 근거가 관측과 정면으로 어긋나 있었다.

## 측정 조건

- 덱: 토브(애장품) + 아르카나: 포츈 메이트 + 소다: 트윙클링 바니 +
  도로시: 세렌디피티 + 드레이크(애장품)
- Burst 3가 셋(소다·도로시·드레이크)인 편성이고, **소다는 격 사이클로 버스트를
  가져간다**(소다 → 다른 B3 → 소다 → …)
- 판독은 인게임 스택 표시

## 원본 — Fienn의 판독 (2026-08-06)

```
풀 버스트 지속시간:            15초
풀 버스트 한 창당 쌓이는 칩:   8스택 정도

궤적:
  50  --(소다 버스트)-->  33
  33  --(FB 종료 시점)-->  40 or 41
      --(다른 B3 버스트, FB 종료 시점)-->  49 or 50
      --(소다 버스트)-->  33
  이후 반복
```

부수 확인: **다른 B3가 버스트한 사이클에도 평타 3회당 1스택이 쌓인다.** 축적은
소다 자신의 버스트와 무관하고 풀 버스트 창에만 종속된다.

## 해석 1 — 15초는 그녀 자신의 미모델 확장이다

풀 버스트의 기본 길이는 10초다. 이 덱에 그것을 늘리는 유닛은 소다뿐이고, 그녀의
Beginner's Rewards가 `Full Burst Duration ▲ 2초`(칩 10+) + `▲ 3초`(칩 20+)를 준다.
관측된 15초 = 10 + 2 + 3이므로 **판독 시점의 칩은 늘 20 이상**이었다는 뜻이고,
위 궤적(33~50)이 그것과 일치한다.

원문이 `Activates when entering Burst Stage 3. Affects all allies.`이므로 **소다가
버스트할 필요가 없다** — 덱의 누가 Burst 3를 쏘든 그녀의 패시브가 발동한다. 실측에서
모든 창이 15초인 것이 이 읽기를 뒷받침한다.

## 해석 2 — 확장을 넣으면 시뮬레이터가 실측을 재현한다

같은 덱·같은 격번 로테이션을 두 번 돌렸다(`scripts/measure_golden_chip.py`와
`FULL_BURST_DURATION_DELTA`를 세 B3에 +5초로 임시 주입한 실험):

```
엔진 그대로 (FB 10초):   창당 fill 6    50 -> 33 -> 39 -> 45 -> 28 -> 34 -> 17 -> 23 -> 6   (고갈)
확장 주입 (FB 15초):     창당 fill 9~10  50 -> 33 -> 42 -> 50 -> 33                        (순환)
```

아래쪽이 Fienn의 판독과 스택 단위로 맞는다(33 → 40/41 → 49/50 → 33). 위쪽은 맞지
않는다. 즉 **시뮬레이터의 고갈은 그녀의 확장을 빼놓은 결과**이지 그녀의 성질이 아니다.

창당 fill은 실측 8에 대해 시뮬 9~10으로 조금 높다(FB 15초에 소다가 27~29발을 쏘는
셈인데, 8스택이면 24발이다). 궤적의 결론은 바뀌지 않지만 **소다의 발수 모델이 실전보다
15%가량 빠를 가능성**이 여기 남아 있다 — 그녀는 9발 장탄에 클립 3분할 재장전이라
재장전 모델에 민감하다. 별도로 확인할 것.

## 이 측정이 결론짓는 것

- **순환에는 안정된 고정점이 있다.** 칩 ≥20 → FB +5초 → 창당 +9~10 → 소다가 격번으로
  17을 써도 2사이클 수지가 +1~2 → 칩이 20 아래로 안 내려감. 자기일관적이다.
  「순환이니 상수로 접을 수 없다」는 판단은 **소다가 매 사이클 버스트하는 운영**에서만
  맞았다(그때는 사이클당 -17+9 = -8로 붕괴한다).
- **미모델의 대가가 크다.** 이 덱에서 확장을 넣으면 총딜이 4.429B → 4.841B(**+9.3%**,
  스케줄러가 고른 로테이션) / 3.027B → 3.282B(+8.4%, 격번 로테이션)다. 소다 혼자가
  아니라 **덱 전원이 풀 버스트 창을 50% 더 갖는다**.

## 이 측정이 결론짓지 않는 것

- 소다가 매 사이클 버스트하는 운영에서 칩이 실제로 붕괴하는지 — Fienn은 격번으로만
  플레이했다. 시뮬레이터는 붕괴한다고 말하지만 실측 대조가 없다.
- 칩이 20 아래로 떨어졌을 때 FB가 정말 12초(= 10+2)가 되는지, 10 아래에서 10초로
  돌아오는지. 실전에서 그 구간에 들어간 적이 없어 판독이 없다.
- 창당 8 vs 9~10의 15% 차이가 재장전 모델 때문인지 공속 버프 차이 때문인지.
