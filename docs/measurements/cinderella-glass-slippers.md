# 신데렐라 Glass Slippers — 다단히트 케이던스와 두 불릿의 연산 시점

Fienn 인게임 실측, 2026-08-15. `GLASS_SLIPPERS_FIRST_HIT_DELAY`(0.95) ·
`GLASS_SLIPPERS_HIT_INTERVAL`(0.2)과, 불릿1을 캐스트 시각에 기록하는 결정이
전부 이 판독에 기대고 있다.

## RAW (편집 금지)

### 케이던스

- 10히트가 **1.80초**에 걸쳐 **0.200초 간격**. FB 잔여 **9.05 → 7.25**로 읽었다.
- 버스트 첫 대미지는 **FB 진입 후 0.95초**에 출력된다.
- 불릿2는 **히트마다** 뜬다 — **10개** 찍혔다.

### 표기 대미지 (논크리만 기록)

편성: 아니스 · 솔린 · 도라 · 헬름: 아쿠아마린 · 신데렐라.
도라 1스킬이 10초마다 자동 발동(스킬 4레벨)이라 두 측정의 버프 상태가 같지 않다.

| | 아름다움 1~2스택 (불확실) | 아름다움 12스택 |
|---|---:|---:|
| 불릿1 | 23,637,148 | 25,033,952 |
| 불릿2 | 1,022,431 | 13,252,351 |

### 앞선 사격장 판독 (2026-07-27, 같은 스킬)

전투 개시 1초의 첫 버스트, 표적 DEF 100, Lv 665, 볼륨·크라운·신데렐라 편성.
불릿1 **12,674,307**(논크리) / **20,958,234**(크리),
불릿2 **513,863** / **737,770**.

## 이 판독이 정한 것

### 1. 불릿2는 히트마다 붙는 라이더이고 스택에 선형이다

두 측정의 버프 상태가 다르므로 **불릿1로 정규화**한다(불릿1은 스택과 무관한
1365.92% 고정이라 편성 버프 차이를 그대로 담는다):

```
불릿1 비  25,033,952 / 23,637,148 = 1.0591
불릿2 보정 13,252,351 / 1.0591    = 12,512,845
스택 비   12,512,845 / 1,022,431  = 12.24
```

12스택 대비 **12.24** → 첫 측정은 **1스택**이었다. 잔차 2%는 아름다움의
Max HP +1.6%/스택이 Flawless Glass의 「Max HP의 2.71%」 ATK를 밀어올리는
간접 효과다(불릿1도 같이 커지므로 정규화가 완전히 약분하지 못한다).

### 2. 불릿1은 FB 보너스를 받지 않고, 불릿2는 받는다

같은 버스트 안에서 두 불릿이 받는 배수를 퍼센트로 정규화하면:

| | 퍼센트 비 | 대미지 비 | 불릿2가 더 받는 배수 |
|---|---:|---:|---:|
| 1스택 | 1365.92 / 28.9 = 47.26 | 23.12 | **2.044** |
| 12스택 | 1365.92 / 346.8 = 3.939 | 1.889 | **2.085** |

두 판독이 일관된다. 불릿1도 FB 보너스를 받았다면 이 값이 1.0 근처여야 한다.
2.06 ≈ FB 보너스 1.5 × 그 창에 붙는 편성 버프 1.39.

### 3. 그래서 버스트 대미지는 캐스트 시점에 확정된다

**첫 히트가 FB 진입 0.95초 뒤**라는 것과 **불릿1이 FB 보너스를 못 받는다**는
것이 같이 성립하려면, 10히트 전부가 FB 창 안에 있으면서도 창의 보너스를 안
받아야 한다. 즉 불릿1의 대미지는 **캐스트 시점에 확정**되고 히트는 그 값을
1.8초에 걸쳐 나눠 꽂는 것이다.

2026-07-27 판독이 이것과 독립적으로 같은 답을 준다: 그때 불릿1은 크라운의
One for All(`full_burst_enter` 버프)도 **안 받은** 값과 소수 5자리로 맞았다.
창이 여는 순간에 도착하는 버프 역시 캐스트에 못 미친다.

## 엔진에 들어간 것

- 불릿1: **손대지 않았다.** `burst_hit_counts`가 10히트를 캐스트 시각에 기록하는
  현행이 위 결론 그대로다. 실제 착탄 시각으로 흩뿌리면 게임이 안 주는 FB
  보너스를 주게 된다.
- 불릿2: `resource_scaled_nukes` 스펙이 `tick_count=10` · `tick_interval=0.2` ·
  신규 `fire_delay=0.95`. 각 틱이 자기 시각의 아름다움 스택을 읽고, 시각이 FB
  창 안이라 보너스는 엔진의 창 검사가 알아서 준다.

## 이 판독이 정하지 못한 것

- **첫 측정의 스택이 1이라는 것은 유도값이다.** Fienn의 기록은 "1 또는 2스택
  (확실하지 않음)"이고, 위 12.24는 1스택을 가리키지만 2%의 잔차를 Max HP
  간접 효과로 설명한 뒤의 이야기다. 스택을 눈으로 확정한 판독이 아니다.
- **2.06 안에서 FB 보너스 1.5와 편성 버프 1.39를 분리하지 못했다.** 두 측정이
  같은 편성이라 그 곱만 보인다. 분리하려면 버프를 안 주는 B1·B2로 편성해
  다시 재야 한다. 다만 "불릿1은 못 받고 불릿2는 받는다"는 결론은 그 분리
  없이도 성립한다(1.0이 아니라는 것만으로 충분하다).
- **0.95초가 캐스트 기준인지 FB 진입 기준인지는 같은 값으로 수렴한다** —
  `burst_cycle.FULL_BURST_OPEN_DELAY`가 1e-6짜리 순서용 엡실론이라 두 시각이
  사실상 같기 때문이다. 엔진은 캐스트 기준으로 더한다.
