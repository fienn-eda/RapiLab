# 재장전 아핀 모델 — 실측 (2026-07-29)

- 측정: Fienn, 60fps 영상 판독
- 이 파일이 존재하는 이유: `attack_rate.RELOAD_FIXED_SECONDS = 0.148`이 이 여섯 점
  위에 서 있다. 상수가 근거 없이 떠다니지 않게 원본을 남긴다.
- 모델이 착륙한 경위: `docs/superpowers/specs/2026-07-31-affine-reload-model-design.md`

## RAW

| 유닛 | 무기 | 파일값 | 무버프 | 큐브만(29.69%) | 큐브+프리바티(80.85%) |
|---|---|---|---|---|---|
| 프리바티 | AR | 1.0초 | 1.1667 | 0.8333 | 0.3500 |
| 라피: 레드후드 | MG | 2.5초 | 2.65 | 1.90 | 0.64 |

## 이 숫자가 정하는 것

- 유닛별로 직선을 맞추면 기울기 **1.0029 / 2.4835** — 파일값 1.0 / 2.5와 일치.
  **데이터 파일은 맞았고 엔진의 식이 틀렸다.**
- 남는 절편 **0.148초**가 AR·MG에서 같다 → 무기군 상수가 아니라 전역으로 읽힌다.
- 잔차 최대 **1.12프레임**(프리바티 무버프). 테스트 앵커는 1.2프레임으로 조인다.
- **역수 형태를 기각한다**: 크라운(44.35%) + 프리바티(51.16%) + 렐릭베어 큐브(29.69%)
  = 125.20%에서 게임은 재장전이 사라지는데 `파일값/(1+s)`는 0.888초를 준다.

## 이 숫자가 정하지 못하는 것

- **★ 원 측정 조건이 기록되지 않았다.** 무엇을 시작점과 끝점으로 쟀는지(탄창이 빈
  프레임? 재장전 모션 시작? 다음 발이 나간 프레임?)가 남아 있지 않다. 0.148초가
  실제 애니메이션 구간인지 **판독 경계의 산물**인지는 이 기록으로 가릴 수 없다.
  다음에 잴 때는 `docs/measurements/bready-charge.md`처럼 프레임 번호를 남길 것.
- **차지 무기에서는 상수가 0으로 읽힌다** — 밀크(SR, 강제 재장전 −50% → 정확히
  2.0×1.5 = 3.0) · 센티(RL, 클립 1회가 정확히 파일값 0.5초 = 30프레임). 전역 상수는
  Fienn 판정(2026-07-31)이며, **무기군별 상수가 살아 있는 대안**이다.
  가르려면 **차지 무기 하나를 무버프로 재장전시켜 프레임을 세면** 된다 — 파일값
  그대로면 무기군별, 파일값+9프레임이면 전역이다.
- ~~**s > 1에서 고정 구간이 남는지**~~ — **✅ 안 남는다 (2026-08-15).** 크라운 +
  프리바티 + 재장전 큐브 15레벨에서 마지막탄 발사 → 재장전 완료가 네 벌 모두
  **2~3프레임**(평균 2.25)이다. 고정 구간 0.148초는 8.9프레임이므로 남을 자리가 없고,
  엔진의 `max(0, ...)`가 옳다. 원본은 `docs/measurements/mg-spinup.md`의
  「다섯 번째 판독」에 있다(같은 영상이 램프 잔존도 같이 준다).
