# 밀크: 블루밍 바니 톡톡이 — 매거진 안 혼합 케이던스

2026-08-19 · Fienn & Bot

## 무엇을 만드는가

밀크의 실제 플레이 조작을 엔진에 넣는다. 앨리스에게 들어간 톡톡이와 **같은 조작이지만
다른 문제**다.

- **앨리스**: 매거진을 통째로 톡톡이로 쏘거나 통째로 풀차지로 쏜다. 두 끝 중 하나.
- **밀크**: 매거진 **안에서 섞는다**. 풀차지가 대미지 말고도 **Pierce 6초를 되살리는
  부수효과**를 갖기 때문이다. 전부 톡톡이로 쏘면 6초 뒤 Pierce가 끊기고, 그러면
  그녀의 「Pierce Damage ▲」 두 클로즈가 통째로 죽는다.

Fienn의 조작(2026-08-19):

1. 1스킬 관통특화를 유지하려고 주기적으로 풀차지 1회.
2. 관통이 유지되는 동안은 톡톡이(약 5초).
3. 관통특화가 꺼지기 1초 전에 1초간 풀차지 — 다시 관통 획득.
4. 자기 버스트 직후 [부끄러움]을 켠다. 다른 B3의 버스트 턴에는 [부끄러움]을 받은
   상태에서 풀차지 → 톡톡이 → 풀차지 → 톡톡이.
5. 자기 버스트 턴에는 [부끄러움] 면역이므로, 관통특화를 유지하는 선에서 톡톡이.

이 다섯 줄이 **하나의 규칙**으로 환원된다: *Pierce 창을 지키는 최소 비용으로 풀차지를
넣고 나머지는 전부 톡톡이*. 4번의 「풀→탭→풀→탭」은 그 규칙이 매거진당 풀차지 2발을
요구하는 경우이고, 별도 분기가 아니다.

## 스킬 원문이 정하는 것

`Embarrassment Suppression`(skills[0]):

> Activates when performing a **Full Charge attack**. Affects self. Gain Pierce for 6 sec.
>
> Activates when not in the Embarrassment state and when **Full Charge lasts for 0.5 sec
> or more**. ... Embarrassment ...

- Pierce는 **풀차지에만** 붙는다. 톡톡이는 갱신하지 못한다 — 이것이 혼합이 필요한 이유다.
- [부끄러움] 진입은 **풀차지를 0.5초 이상 유지**해야 한다. 톡톡이로는 안 켜진다.
  현재 `embarrassment_entry_offset`(면역 10초 + 차지 1초 + 유지 0.5초 = 11.5초)은
  이 조작 아래서도 그대로 유효하다.

## 설계

### 1. 최적 풀차지 발수 `k`

매거진 하나에 풀차지 `k`발 + 톡톡이 `C−k`발을 넣는다. 기호:

| | 뜻 |
|---|---|
| `C` | 매거진 용량 (장탄 버프·오버로드 반영) |
| `R` | 재장전 시간 (재장전 버프 반영) |
| `T` | 차지 시간 (차속·차지감소 반영) |
| `D_full` | 풀차지 뒤 멈춤 |
| `D_tap` | 톡톡이 발 간격 |
| `M` | 풀차지 배율 (밀크 2.5) |
| `W` | 풀차지를 다시 쳐야 하는 창 (밀크 6초 · 앨리스 없음) |

```
대미지(k) = C + k(M − 1)
시간(k)   = C·D_tap + R + k(T + D_full − D_tap)
효율(k)   = 대미지(k) / 시간(k)
```

**효율은 `k`에 대해 단조다.** `(p + ak)/(q + bk)` 꼴이라 도함수 부호가 `k`와 무관하고,
그 부호는 `s = a·q − b·p` 하나로 정해진다(`p=C`, `a=M−1`, `q=C·D_tap+R`,
`b=T+D_full−D_tap`). 앨리스의 「중간 지점은 항상 지배당한다」와 같은 구조다 — 답은 항상
허용 구간의 **양 끝** 중 하나이지, 중간의 어떤 `k`가 아니다.

**Pierce 창 제약.** `k`발을 매거진 안에 균등 배치하면 한 블록이 최대 `ceil(C/k)`발이고,
재장전은 그중 한 블록에 통째로 붙는다. 그래서 연속한 두 풀차지 사이의 **최악 간격**은

```
(T + D_full) + (ceil(C/k) − 1)·D_tap + R  ≤  W
```

`W`가 없는 유닛(앨리스)은 이 제약이 없고 `k=0`이 허용된다.

**구현은 `k = 0..C`를 훑어 제약을 만족하는 것 중 효율 최대를 고른다.** `C`가 작아
비용이 없고, `ceil` 보정이 들어간 제약을 근사 없이 정확히 처리한다. 단조성은 코드가
기대는 성질이 아니라 *왜 답이 양 끝에 붙는지*를 설명하는 근거로 문서에 남긴다.

**어떤 `k`로도 창을 못 지키면 `k=C`(전부 풀차지)로 간다.** 그것이 그 상황에서 풀차지를
가장 자주 치는 배치이기 때문이다 — 그때 최악 간격은 `(T + D_full) + R`까지 줄고, 그보다
짧게 만들 방법은 없다.

**다만 그 값도 창을 넘을 수 있다.** 재장전 하나가 창보다 길면 어떤 케이던스로도 창을 못
지킨다. 그때는 모델이 아니라 게임이 창을 잃는 것이고, 이 폴백이 보장하는 것은 「창을
지킨다」가 아니라 **「지킬 수 있으면 지킨다」**이다. (2026-08-19 Ruling 4 — 처음 이 자리에는
「전부 풀차지는 언제나 창을 지킨다」고 적혀 있었고, 그것은 거짓이었다. Task 2 리뷰가
`장탄 6 · 재장전 8초`에서 최악 간격 9.37초 > 창 6초로 반증했다.)

밀크의 실제 값은 이 분기에 닿지 않는다 — `T + D_full + R` = 1.37 + 2.0 = **3.37초 < 6초**이고,
그녀의 강제 재장전 3.0초를 넣어도 4.37초다(파일값 기준. 엔진은 재장전을 아핀으로 써서
`RELOAD_FIXED_SECONDS` 0.148초를 더하므로 엔진이 실제로 쓰는 값은 3.515초·강제재장전
4.515초다 — 어느 쪽이든 6초 창 아래다). **그것이 §설계 4의 Pierce 영구 부여가 실제로
기대는 부등식이고**, 그 부등식이 깨지는 날 그 근사는 근사가 아니라 오류가 된다.

### 2. 매거진 안 배치

풀차지 위치 = `{floor(j·C/k) : j = 0..k−1}`. `j=0`이 0번 탄이므로 **첫 탄은 항상
풀차지**이고, 이는 Fienn 조작 4번(「첫 탄 풀차지」)과 강제 재장전 직후의 거동을 함께
만족한다.

지금 `_base_shot_records`의 차지 분기는 매거진 전체가 한 간격이라
`shot_time = magazine_start + charge + i·charge`로 계산한다. 발마다 소요가 갈리므로
**누적합**으로 바꾼다. `ShotRecord.extra_charge_bonus`도 발마다 갈린다(풀차지면 `full_bonus`, 톡톡이면 0).

### 3. registry 선언 두 개

- `TAP_FIRE_INTERVAL` — 톡톡이 발 간격의 **실측 표**. 없으면 그 유닛의 멈춤을 쓴다
  (지금 동작과 같으므로 앨리스는 값이 같아 회귀가 없다).
- `FULL_CHARGE_WINDOW` — 풀차지를 얼마마다 쳐야 하는지. 밀크 `6.0`.
  스킬의 「Gain Pierce for 6 sec」에서 읽은 값이지 조작에서 나온 값이 아니다.
- `TAP_FIRE_CANDIDATES`에 `milk-blooming-bunny` 추가.

registry의 낡은 주석 두 곳을 고친다: 「톡톡이 간격 = 멈춤」 문단과 「밀크·아인의 멈춤을
다시 재기 전까지 끄고 둔다」(밀크 멈춤은 2026-08-15에 이미 실측됐다 — 주석이 그때 이후로
갱신되지 않았다).

### 4. Pierce 영구 근사의 근거 교체 — **가장 조심할 곳**

지금 `milk_blooming_bunny.py`는 Pierce를 `battle_start`에 영구로 준다. 그 근거는

> her every shot IS a full charge, so the window never lapses

인데, **톡톡이를 넣으면 이 문장이 거짓이 된다.** 근거를 바꾸지 않고 케이던스만 바꾸면
엔진은 톡톡이만 쏘면서 Pierce를 공짜로 받는다 — 밀크를 과대평가한다.

새 근거는 **그녀의 숫자에 관한 부등식**이다. 케이던스는 창을 지킬 수 있으면 지키도록
`k`를 고르고, 지킬 수 없으면 창을 가장 덜 잃는 `k=C`로 물러난다(§설계 1). 그러니 영구
부여가 정당한지는 **그녀가 「지킬 수 없는」 분기에 닿는가**에 달렸고, 닿지 않는다:

```
T + D_full + R  =  1.0 + 0.367 + 2.0  =  3.37초  <  6초 = W
```

그녀의 강제 재장전(「50% 감소 고정」 = 3.0초)을 넣어도 4.37초다. (파일값 기준이며 엔진은
재장전에 `RELOAD_FIXED_SECONDS` 0.148초를 더한다 — 3.515초, 강제 재장전이면 4.515초.
어느 쪽이든 창 6초 아래다.) 어떤 매거진에서도 창을 지킬 수 있으므로 케이던스가 실제로
지키고, 영구 부여는 그 결과를 옮겨 적은 것이다.

**이 부등식이 근사의 전부다.** 그것이 깨지는 날 — 창이 더 좁은 유닛이 오거나 재장전이
길어지면 — 영구 Pierce는 근사가 아니라 오류가 된다. 그래서 테스트가 「어느 분기에서도
유지된다」가 아니라 **이 부등식 자체**를 못박는다(§6).

### 5. 앨리스 회귀 방지

`W`가 없으면 `k_min = 0`이 허용되고, 그때 새 경로의 판정이 기존 `tap_fire_wins`와
**동치**임을 대수로 확인했다: `f(0) > f(C) ⟺ s < 0`. 테스트로 고정한다.
